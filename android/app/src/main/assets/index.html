    Om os
    Ekstra · valgfrit

    Sæt siden online

    Gratis med GitHub Pages. Du bruger den samme GitHub-konto som til appen. Det tager ca. 5 minutter.

    1 · Gem siden

    Tryk Gem fil i Hjemmesidemaskinen. Filen hedder index.html. Behold det navn, ellers virker det ikke.

    2 · Lav et repository

    Gå til github.com/new. Giv det kundens navn, fx salon-nova, vælg Public (det kræver den gratis plan) og tryk Create repository.

    3 · Upload filen

    Tryk uploading an existing file, vælg index.html og tryk Commit changes.

    4 · Slå GitHub Pages til

    Gå til Settings → Pages. Under Branch vælger du main og / (root) og trykker Save.

    5 · Siden er online

    Efter 1–2 minutter ligger den på dit-brugernavn.github.io/salon-nova. Skriv adressen i feltet Adresse på nettet, så kommer linket med i dine beskeder.

    Åbn GitHub
    Eget domæne til kunden

    Kunden køber selv et domæne, fx salonnova.dk, hos en dansk udbyder. Skriv det under Settings → Pages → Custom domain, og følg GitHubs vejledning til DNS-indstillingerne.

    Når kunden vil have noget rettet

    Ret siden i appen, tryk Gem fil, og upload index.html igen oven i den gamle. Det er det, kunden betaler det faste beløb om måneden for.

    Forbind GitHub

    Det gør du én gang, og det tager ca. 3 minutter. Derefter lægger appen hjemmesider online med ét tryk.

    1 · Lav en nøgle

    Tryk på knappen herunder. Log ind på GitHub, hvis den spørger. Navn og hak ved repo er allerede sat.

    2 · Vælg udløb

    Ved Expiration vælger du No expiration (eller 1 år).

    3 · Lav og kopiér

    Rul ned, tryk Generate token, og kopiér koden, der starter med ghp_.

    4 · Sæt den ind her

    Sæt koden ind i feltet, og tryk Forbind.

    Lav nøgle på GitHub

    Nøglen gemmes kun på denne telefon. Den kommer ikke med i backup eller synkronisering. Del den aldrig med andre.
